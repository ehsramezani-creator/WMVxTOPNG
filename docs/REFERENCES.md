# Reference Repositories

## warcraft-rs

Primary binary-format reference for WoW M2/SKIN structures and version differences.

## wow.export

Practical reference for M2/SKIN discovery, model loading, textures, materials, and rendering behavior.

## WMVx

Reference for the existing `M2LegacyLoader` and renderer architecture.

## WMVx-MPQ-FBX-Exporter

Separate native C++ project used for MPQ, M2, SKIN, texture, and FBX investigation.

## Rule

References are used to establish facts and compare implementations. The target implementation belongs in WMVxTOPNG and should not become unnecessarily coupled to any reference repository.
